How it works

Three keys. You stay the reviewer.

Diagnose

Reads the failed job's logs and your code, and tells you the cause in one line, with the file and line number.

Repair

Writes the smallest fix on its own greenci/* branch. Never on main. Never merged without you.

Verify

Re-runs every check on the fix. Only when they all pass does it open a pull request for you to review.

✕ test (ubuntu) failed on main · acme/payments
✔ Cause  fixture date 2026-10-31 is now in the past · tests/billing.spec.ts:41
✔ Fix    1 file  +3 −1  on greenci/fix-4182
✔ 12/12 checks passing · PR #418 ready for review         example run
