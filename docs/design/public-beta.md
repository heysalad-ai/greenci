Mode: Operate. This is a narrow extension of the established GreenCI beta form, not a new visual identity. Brand and token authority remain in design-system/.

## Direction contract

THESIS: A visitor can understand the supported repair, its data use and limits, then continue with GitHub without finding an invitation code.

OWN-WORLD: Preserve the existing GreenCI logo, neutral surface, green primary button, Bricolage heading and token-based spacing, borders and keyboard focus. No new colours, imagery or components.

STORY: Read the repair boundary, understand OpenAI data use and beta capacity, sign in, install on selected repos, connect a repo and review a draft repair. A public practice template provides a supported first repository.

FIRST VIEWPORT: Existing header with logo and dashboard link; a left-aligned, single-column form within the established 720px panel. Title, concise purpose, scope and limits precede the data-use link and green GitHub button. The practice-template link follows as secondary help. Preserve a readable narrow-screen flow.

FORM: Existing single-column beta flow, extended directly for this precise task. No composition tournament, seed or new-world approval applies to this narrow extension.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

This extension adds no shipping raster and does not author or replace a design system. The documenter checks incumbent tokens/components and reports drift without rewriting them.
