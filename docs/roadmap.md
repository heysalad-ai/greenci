# GreenCI pad roadmap

V1 stays Wi-Fi only, with authenticated remote controls and OTA updates.

After V1: evaluate standalone cellular connectivity. Start with a phone-hotspot
journey, then assess a modem/SIM/antenna/power design if phone independence is
needed. Cellular hardware and firmware are deferred.

Before treating battery percentages as verified: compare voltage with a meter,
confirm the pack's power/protection path, and validate the cell-specific profile.
