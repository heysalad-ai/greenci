# Logo

The GreenCI logo is the smiling keycap (two check-mark eyes and a smile on an emerald key with a charcoal base) followed by the GreenCI wordmark.

- Use the files in the **Logos** asset group; never retype the wordmark or redraw the key.
- Default: `greenci-logo.svg` on `surface` or white. On `deck` or any dark ground use `greenci-logo-on-dark.svg`.
- One-colour work (engraving, moulding, embroidery, single-ink print): `greenci-logo-black.svg` or `greenci-logo-white.svg`.
- Square spaces (packaging, app stores, the underside of the deck): `greenci-logo-stacked.svg`.
- Below 20px use `greenci-favicon.svg` (a single check, no face). The printed command key uses `greenci-check.svg`.
- Clear space: the height of the key's base lip (one seventh of the symbol) on every side. Minimum widths: symbol 16px, horizontal logo 96px.
- Always keep the charcoal base lip. It is what separates the GreenCI key from a generic green check.
- Don't: recolour the face, add gradients or shadows, rotate, set the key in an outline, or put the full-colour logo on emerald (use white one-colour instead).
