# Terminal

How GreenCI looks in a terminal and in logs shown inside the app: a dark well whatever the theme, with four status glyphs.

- Glyphs: `●` info (work), `◐` in progress (work), `✔` done (brand), `✕` failed (fail). Colour and glyph always together.
- Every block ends with one “Next:” line naming the key to press and the command to type.
- Keep lines under 80 characters; never print emoji or ASCII art beyond the glyphs.
