# CommandField

The command palette and agent input: a monospaced field with an emerald prompt and a key hint. It mirrors the deck's command key.

- Markup: `<label class="gc-cmd"><span class="p">›</span><input…><span class="gc-kbd">⌘K</span></label>`.
- Placeholder invites both modes: “Ask GreenCI or type a command”.
- Opens with ⌘K anywhere in the app, or a long press on the deck's command key.
